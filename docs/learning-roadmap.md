# Study Planner learning roadmap

## Stage 1 — HTML

Use `Frontend/templates/index.html` to practise document structure, semantic sections, forms, lists, classes, and IDs.

**Challenge:** Add a profile section and a table that lists the task, category, deadline, and status.

## Stage 2 — CSS

Use `Frontend/static/css/styles.css` for selectors, spacing, colours, cards, Flexbox/Grid, hover states, and responsive breakpoints.

**Challenge:** Make the task list into responsive cards without changing the HTML structure.

## Stage 3 — Python

Put reusable task-management exercises in `Backend/app/services/`.

**Challenge:** Write a program that adds, displays, and removes tasks from a list.

## Stage 4 — Flask

Add routes to `Backend/app.py` to display tasks and accept form submissions.

**Challenge:** Render a Python list of tasks on the home page.

## Stage 5 — Database

Store the local SQLite file in `Database/instance/`; it is ignored by Git to keep personal data out of the repository.

**Challenge:** Make tasks persist after restarting the application.

## Next features

- Complete, edit, and delete tasks
- Deadlines and categories
- Search, filters, and progress statistics
- Validation and error messages
- Accounts, authentication, and personal task lists
